# Feature: `envx interactive`

## Summary

Guided setup of the `.envrc` secrets file — the passphrases EnvX uses to
encrypt/decrypt each stage. Source: `src/commands/interactive.ts`.

## Usage

```bash
envx interactive              # guided setup
envx interactive --overwrite  # replace existing .envrc without asking
envx interactive --generate   # generate random secrets
```

## Flags

| Flag               | Meaning                                              |
| ------------------ | ---------------------------------------------------- |
| `--overwrite`      | Overwrite an existing `.envrc` without confirmation. |
| `--generate`       | Generate random secrets for stages.                  |
| `-c, --cwd <path>` | Working directory.                                   |

## Behavior

1. Show welcome; validate options (Zod).
2. Discover existing environments (drives which stages to prompt secrets for).
3. If `.envrc` exists and no `--overwrite`:
   - Offer to display current secrets (keys ending `_SECRET`, values not shown).
   - Ask whether to overwrite. Declining keeps the file and prints usage help.
4. `InteractiveUtils.setupEnvrc(cwd, existingEnvironments)` collects secrets per
   stage (prompted or generated).
5. `writeEnvrc` writes `export <STAGE>_SECRET="…"` lines with the
   `# Environment secrets generated by envx` header.
6. Print usage help (the `envx encrypt -e <stage>` commands now available) and
   direnv integration guidance (detects whether `direnv` is installed).

## Output helpers

- **Usage help** lists `envx encrypt/decrypt -e <stage>` for each configured
  secret, plus the `-s CUSTOM_SECRET` form.
- **direnv setup** detects `direnv --version`; if present, suggests
  `direnv allow`; if not, prints install steps. Always ends with the security
  reminder: never commit `.envrc`, add it to `.gitignore`.

## Edge cases (from code)

| Scenario                            | Behavior                                                       |
| ----------------------------------- | -------------------------------------------------------------- |
| `.envrc` exists, decline overwrite  | Keep file, show usage help, return.                            |
| Setup cancelled by user             | Catch `Setup cancelled by user`, info + return (not an error). |
| Write fails                         | Error + exit `GENERAL_ERROR (1)`.                              |
| No secrets yet in existing `.envrc` | Warn "No secrets found".                                       |

## Notes

- `.envrc` is git-ignored and holds the actual passphrases — never commit it.
- This command is also invoked from `envx init` when the user opts into secret
  setup during first-run.

## Exit codes

`SUCCESS 0` · `GENERAL_ERROR 1`.
